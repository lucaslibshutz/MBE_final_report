# MBE Final Report: Ackermann Car Model 

This repository contains the paper associated with the [`ackermann-jax`](https://github.com/cornellev/ackermann-jax) repository, which implements the Ackermann car model in JAX. The paper provides a detailed analysis of the model, including its mathematical formulation, implementation details, EKF implementation & results, along with future steps for MPC and other algorithms.
